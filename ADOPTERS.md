# mcp-bastion adopters

This is a list of organizations that use mcp-bastion, in production or in a pilot. Each entry is
added by **a pull request from someone at that organization**, so every row is a public statement
by the adopter themselves.

If you use mcp-bastion, we'd love to have you here. It helps other teams judge whether the project
fits them, and it tells the maintainers what to prioritise.

## Adding your organization

1. Fork the repo and add a row to the table below, in alphabetical order by organization.
2. Open a pull request **from an account that belongs to someone at that organization**, with the
   title `ADOPTERS: add <organization>`.
3. Your PR is your confirmation. Please make sure you're allowed to name your organization
   publicly. Many companies need sign-off from comms or legal first.
4. If you can't be named publicly, you're still welcome to tell the maintainers privately. We
   won't list anyone who hasn't opened a PR.

| Field             | What to write                                                                                                                                       |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Organization**  | Legal or commonly used name, linked to its website                                                                                                  |
| **Contact**       | GitHub handle of a person we can ask follow-up questions (optional: a role, e.g. "Platform Security")                                               |
| **How it's used** | One or two sentences: which clients and servers, which mode (`observe` / `balanced` / `strict`), audit sinks, rough scale (teams, users or servers) |
| **Stage**         | `evaluation`, `pilot` (shadow / `observe`), or `production` (enforcing)                                                                             |
| **Since**         | Month and year you started (e.g. `2026-11`)                                                                                                         |

Want to change or remove your entry? Open a PR. We'll merge removal requests without
questions.
